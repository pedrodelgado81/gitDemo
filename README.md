# gitDemo
## Repositorio de demostración de uso de GIT
Este repositorio no es de un proyecto de código fuente. Se limita a contener los ficheros y ramas necesarios para operar con git


## Recursos
- Simulador de git: https://learngitbranching.js.org/?NODEMO=&locale=es_ES
    - No tiene todos los comandos de git, solo los justos para poder simular trabajo con ramas
- Palabras clave para poner en el texto de un commit referenciando a una issue y automatizar funciones en github: https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/using-keywords-in-issues-and-pull-requests
- Iconos para poner en el texto de un commit: https://gist.github.com/parmentf/035de27d6ed1dce0b36a
